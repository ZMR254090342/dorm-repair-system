# 宿舍报修管理系统

## 项目介绍

基于 AI 辅助开发的多角色宿舍报修工单管理系统，覆盖学生报修、管理员派单、维修处理、数据统计、用户权限管理，实现线上报修、工单流转、进度查询、评价统计一体化，替代传统线下登记方式。

## 角色说明

| 角色 | 主要职责 |
|------|----------|
| 学生 | 提交报修、查看进度、取消工单、评价服务 |
| 后勤管理员 | 审核工单、派单/驳回、管理工单、查看统计 |
| 维修人员 | 接收工单、更新维修状态、完成维修 |
| 超级管理员 | 账号管理、权限分配、系统设置 |

## 功能清单

- 登录注册（学生自助注册、账号密码登录、会话认证）
- 报修提交（楼栋/房号/故障类型/描述/图片，表单校验与提交确认）
- 工单流转（审核、派单、驳回、取消）
- 维修接单（接单、维修中、完成、维修备注）
- 评价反馈（星级评分 + 文字评价，按工单仅可评价一次）
- 数据可视化统计（故障类型饼图、工单状态柱状图、维修人员排行）
- 用户管理（新增、编辑、禁用、重置密码、角色权限）

## 工单流程

```
待审核 → 待维修 → 维修中 → 待评价 → 已完成
```

其他状态：**已驳回**、**已取消**。

- 管理员审核通过并派单后进入「待维修」；审核驳回则工单结束。
- 学生在审核前可主动取消。
- 已驳回、已取消、已评价的工单不可再次评价。

## 技术栈

- 前端：React + Vite + TypeScript + Tailwind CSS + shadcn/ui
- 后端：NestJS + TypeScript
- 数据库：PostgreSQL（Drizzle ORM）
- 图表：ECharts
- 密码加密：bcryptjs

## 快速开始

### 环境要求

- Node.js >= 22.0.0
- npm >= 10.0.0
- PostgreSQL 数据库（本地运行需自行准备，并配置数据库连接）

### 安装依赖

```bash
npm install
```

> 项目 `.npmrc` 默认使用 npmmirror 镜像源：`https://registry.npmmirror.com/`。

### 本地开发

```bash
# 同时启动前端与后端（推荐）
npm run dev

# 或分别启动
npm run dev:server   # NestJS 后端（watch 模式）
npm run dev:client   # Vite 前端开发服务器
```

前端开发端口由环境变量 `CLIENT_DEV_PORT` 决定（默认通常为 8001），后端端口由 `SERVER_PORT` 决定（NestJS 默认 3000），以实际配置为准。

### 生产构建

```bash
npm run build
```

构建产物输出到 `dist/` 目录（包含服务端、前端及运行脚本）。

### 生产运行

```bash
npm start
# 等价于：NODE_ENV=production node main.js
```

或进入构建产物目录执行：

```bash
cd dist && ./run.sh
```
